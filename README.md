A single-page portfolio for a Computer Science and Engineering student working across **full-stack development, AI/ML, computer vision and data analysis**. It is one HTML file with no framework, no build step and no external libraries.

**Live site:** `https://kalaigarmukhtarahmed.github.io`

## What makes it different

- **Animated network background** that reacts to the mouse, with a typing headline and animated counters.
- **Filterable project cards** with a 3D tilt effect. Each card opens a detail panel and links straight to its repository.
- **FleetSync in motion:** a playable simulation of the workflow described in the FleetSync README. Assign a shipment as the dispatcher, move it through transit as the driver, and watch the public tracker build its timeline. It uses sample data in your browser and is not the live application.
- **Honest evidence tags.** Every project is marked *source-verified* (the code was read) or *documented* (described in its README or notes).
- Responsive layout, keyboard-friendly modal (Esc closes it) and reduced-motion support.

## Deploy it on GitHub Pages (2 minutes)

1. On GitHub, create a **public** repository named exactly `kalaigarmukhtarahmed.github.io`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait about a minute. Your site appears at `https://kalaigarmukhtarahmed.github.io`.
5. Add that URL to your GitHub profile (**Edit profile → Website**) and to your profile README, so visitors find it immediately.

## Customise

Everything lives in `index.html`.

- **Projects:** edit the `P` array near the top of the script (name, summary, stack, highlights, evidence note, repository name).
- **Colours:** change the variables in the `:root` block at the top of the stylesheet.
- **Headline words:** edit the `W` array.
- **Contact links:** add your LinkedIn or email in the navigation bar and footer once you decide to share them.
- **Screenshots:** when you capture real FleetSync screenshots, add them under `docs/screenshots/` and reference them in the FleetSync detail panel.
